# Facet 1.0

Initial public release of Facet, the classic Launchpad-style app launcher for macOS.

## What's new

- Familiar app grid for launching Mac apps.
- Keyboard search and app opening.
- Folder organization and persisted app layout.
- Launchpad layout import.
- Paid license activation through Dodo Payments.
- Sparkle automatic updates.
- Developer ID signed and Apple-notarized release.
