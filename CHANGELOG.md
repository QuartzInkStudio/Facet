# Changelog

## Facet 1.0.1 - 2026-05-21

Bug fix release.

### Fixed

- Facet now automatically refreshes when apps are added to or removed from monitored macOS application folders.
- Deleted apps are removed from saved layouts and folders instead of leaving stale icons behind.
- Newly installed apps are appended to the launcher layout without requiring a manual refresh.

## Facet 1.0 - 2026-05-20

Initial public release.

### Added

- Classic Launchpad-style app grid for macOS.
- Keyboard search and quick app launching.
- Folder organization and app layout persistence.
- Launchpad layout import.
- Dodo Payments license activation for paid unlock.
- Sparkle automatic update support.
- Developer ID signed and Apple-notarized distribution.
